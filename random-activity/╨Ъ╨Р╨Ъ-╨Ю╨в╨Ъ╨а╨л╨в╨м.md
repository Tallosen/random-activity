# Random Activity — как открыть на телефоне

Три способа, от самого простого к самому надёжному. Начни с первого — если сработает, дальше можно не читать.

---

## Способ 1. Без интернета, ярлык на главном экране

Ничего никуда выкладывать не нужно. Понадобится только файл `index.html`.

**Шаг 1.** Скинь `index.html` себе в Telegram (в «Избранное») и на телефоне нажми «Сохранить в загрузки». Файл окажется в папке `Download`.

**Шаг 2.** Установи Firefox из Play Market, если его нет.

**Шаг 3.** Открой Firefox и в адресную строку впиши целиком:

```
file:///storage/emulated/0/Download/index.html
```

Нажми «Перейти». Приложение должно открыться.

Если пишет, что файл не найден, попробуй по очереди:

```
file:///sdcard/Download/index.html
file:///storage/emulated/0/Downloads/index.html
```

А чтобы просто посмотреть, что вообще лежит в загрузках, набери `file:///sdcard/Download/` — откроется список файлов, и на нужный можно просто нажать.

**Шаг 4.** Меню ⋮ (три точки справа вверху) → пролистай до пункта **«Добавить на главный экран»** (может называться «Установить»). Готово, иконка на экране.

**Что проверить сразу:** открой приложение с иконки и посмотри, нет ли сверху красной плашки «Браузер не сохраняет данные». Если её нет — всё хорошо, месяцы сохраняются, пользуйся. Если есть — переходи к способу 2 или 3.

---

## Способ 2. Neocities — бесплатно, без Git, без карты

Подойдёт, если первый способ не сработал.

1. Зайди на `neocities.org`, нажми **Sign up**. Нужны только имя пользователя, почта и пароль. Карту не спрашивают.
2. Придумай имя сайта — оно станет адресом вида `имя.neocities.org`.
3. После регистрации попадёшь в раздел с файлами. Нажми **Upload** и загрузи **все файлы из архива** сразу: `index.html`, `manifest.webmanifest`, `sw.js` и четыре картинки `.png`.
4. Если там уже лежит готовый `index.html` — просто перезапиши своим, файлы с одинаковым именем заменяются.
5. Открой на телефоне `https://твоё-имя.neocities.org` → меню ⋮ → **«Установить приложение»**.

Все файлы в архиве лежат в одной куче специально — на Neocities неудобно создавать папки.

## Способ 3. GitHub Pages — самый надёжный

1. Регистрация на `github.com`.
2. **+** справа вверху → **New repository** → имя `random-activity` → **Public** → **Create**.
3. **uploading an existing file** → перетащи все файлы из архива → **Commit changes**.
4. **Settings** → слева **Pages** → **Source: Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
5. Через минуту-две вверху появится адрес `https://твой-логин.github.io/random-activity/`.
6. Открой его на телефоне → меню ⋮ → **«Установить приложение»**.

**Про безопасность.** Публичный репозиторий значит «все могут посмотреть код», но менять файлы можешь только ты. Доступа к твоему компьютеру или телефону через это ни у кого не появляется — там лежит обычный текстовый файл. Единственное, что стоит сделать: поставить нормальный пароль и включить двухфакторную аутентификацию в настройках GitHub.

**Важно:** никогда не заливай в репозиторий файл резервной копии `random-activity_дата.json` — вот в нём как раз твои цифры, и он станет публичным. Держи его только в телефоне.

## iPhone

Способ 1 не работает — Safari не открывает файлы с диска. Нужен способ 2 или 3, дальше: открыть адрес **в Safari** (не в Chrome) → кнопка «Поделиться» → **«На экран Домой»**.

---

## Резервные копии

Данные хранятся внутри телефона и никуда не отправляются. Но и не переезжают сами.

Раз в пару недель заходи в **«Ещё» → «Сохранить резервную копию (JSON)»**. Приложение само напомнит, если давно этого не делал — внизу под таблицей появится строчка с кнопкой.

Восстановить: **«Ещё» → «Загрузить из файла»**.

Не чисти данные браузера для этого сайта — вместе с ними удалятся месяцы.

---

## Обновление приложения

Если пришлю новую версию: залей новый `index.html` вместо старого и в файле `sw.js` поменяй строчку `const VERSION = 'ra-v1'` на `'ra-v2'`. Без этого телефон продолжит показывать старую версию из своей памяти. Заполненные месяцы при обновлении сохраняются.
